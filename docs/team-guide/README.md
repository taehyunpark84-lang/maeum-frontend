# 팀원 안내 문서

두 문서는 2026-11-18 현재 코드와 설정을 확인해 작성했습니다.

1. [프로젝트 구조 안내](../../output/pdf/01_프로젝트_구조_안내.pdf): 기술스택, 코드 지도, GPT 모델과 설정, 데이터 관계, 팀 협업 주의사항. 12쪽.
2. [기능 흐름 안내](../../output/pdf/02_기능_흐름_안내.pdf): 로그인, 공통 기억, 공간별 캐릭터, 최근 이야기 선별, 그림·시 제작, 전달과 보관. 13쪽.

가로 16:9 PDF입니다. 전체 화면 보기로 읽으면 발표 자료처럼 사용할 수 있습니다.
모델명은 현재 설정 기준입니다. 모델 우열이나 속도 비교 실험 결과를 뜻하지 않습니다.
실제 키와 사용자 대화 내용은 포함하지 않았습니다. 그림은 앱의 배경 자산을 사용했습니다.
각 페이지 하단에 근거가 되는 코드 위치를 적었습니다.

## 문서 수정

`build_guides.py`는 PDF를 다시 만드는 문서용 코드입니다. 앱 실행에 쓰이지 않습니다.
Python의 reportlab과 Windows 맑은 고딕 폰트가 필요합니다.
저장소 루트에서 `python docs/team-guide/build_guides.py`로 다시 만듭니다.
변경 후 PDF를 이미지로 렌더링해 겹침과 잘림을 확인하세요.
