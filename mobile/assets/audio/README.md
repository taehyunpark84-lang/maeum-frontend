# 배경음 초안 (2026-11-13)

## 실제 앱 연결 업데이트

현재 앱은 사용자 녹음에서 편집한 `forest-loop-small.mp3`만 사용합니다. 아래의 6개 합성 WAV는 과거 초안이며 실제 재생 맵에 연결하지 않았습니다. 재생 기능과 다른 공간 음원 등록 방법은 저장소 `docs/AUDIO.md`를 참고하세요. 기존 `미리듣기.html`은 합성 초안 청취용입니다.

`미리듣기.html`을 PC 브라우저에서 열거나 WAV 파일을 음악 플레이어에서 열어 청취합니다.

- 6개 파일, 각 20초 / PCM WAV / 22,050Hz / 16bit / mono.
- 파일당 882,044바이트, 합계 5,292,264바이트 (약 5.29MB).
- 외부 녹음·음악 샘플을 사용하지 않고 `scripts/generate_ambience.py`로 합성한 초안. 자연 현장 녹음은 아님.
- 주기적 잡음과 경계에 걸친 효과음 꼬리를 연결하여 반복하도록 생성. WAV 자체에 압축 인코더 지연이 없음. 실제 플레이어에서의 무간격 반복은 별도 확인 필요.
- 수치상 클리핑 없음. 청취 취향·자연스러움에 대한 사용자 검토와 실제 기기의 반복 재생 확인 필요.
- 앱 음원 맵과 재생 기능은 아직 미연결. 파일 추가만으로 앱에서 소리가 나지는 않음.
- 카페 파일은 빗소리 중심이며 대화·음악 샘플은 포함하지 않음.
- 상세 수치는 `manifest.json`. 재생성에는 Python과 numpy 필요.
