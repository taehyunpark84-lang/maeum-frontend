# 배경음 재생과 음원 추가

## 현재 연결

- `mobile/assets/audio/forest-loop-small.mp3`: 사용자 제공 새소리를 반복용으로 편집한 24초 MP3(578,060바이트).
- 6개 공간 모두 실제 반복용 MP3 연결. 기존 합성 초안은 사용하지 않음.

| 공간 | 앱에 포함된 파일 | 길이 |
|---|---|---|
| 숲속 쉼터 | forest-loop-small.mp3 | 24초 |
| 노을 바닷가 | ocean-loop-small.mp3 | 20초 |
| 비 오는 카페 | cafe-loop-small.mp3 | 17초 |
| 고요한 산사 | temple-loop-small.mp3 | 6초 |
| 비밀정원 | garden-loop-small.mp3 | 24초 |
| 성당 | cathedral-loop-small.mp3 | 17초 |

6개 MP3 합계 2,605,224바이트(약 2.48MiB). 추가 5개는 `output/audio/room-loops`의 편집 결과를 그대로 복사함.
- `mobile/src/config/assets.ts`의 정적 음원 맵만 재생기에서 참조하므로, 확인용 WAV·HTML 등은 앱 코드에서 불러오지 않음.

## 사용법과 동작

1. 공간 소개의 재생 버튼 또는 채팅 → 소리 설정 → 재생 버튼으로 시작.
2. 일시정지는 위치를 유지. 정지는 처음(0초)으로 이동. 한 번 재생을 끝낸 뒤 다시 재생하면 처음부터 시작.
3. 반복 스위치는 기본 켜짐. native player의 loop를 사용하며 JS 타이머로 파일을 재시작하지 않음.
4. 볼륨 슬라이더는 즉시 적용·저장. 음소거는 볼륨을 잃지 않고 끄고 켤 수 있음. 슬라이더를 움직이면 음소거가 해제됨.
5. 소개 → 같은 공간 채팅, 소리 설정 시트 닫기, 배경만 보기는 재생 유지.
6. 공간 선택으로 나가기, 다른 장소 선택, 일기 화면 진입 시 기존 플레이어 정지·해제. 다음 공간의 파일이 있으면 새 플레이어로 준비하고, 사용자가 재생을 눌러 시작. 음원 없는 공간에서는 새 플레이어를 만들지 않음.
7. 앱 비활성·홈 이동·잠금 시 일시정지. 복귀 후 자동 재생하지 않음. 앱 재시작 시 볼륨·음소거·반복 설정만 복원하고 재생 위치·재생 상태는 복원하지 않음.
8. 파일 로드 오류/12초 로드 시간 초과 시 안내와 다시 불러오기 제공.

## 음원 교체 (화면과 재생기 수정 불필요)

`mobile/assets/audio/`의 해당 `*-loop-small.mp3` 파일을 교체하면 기존 등록을 그대로 사용할 수 있음. 파일명을 변경할 때는 `mobile/src/config/assets.ts`의 해당 정적 require 경로도 함께 수정. 현재 모든 장소가 등록되어 있으며, 향후 음원이 없는 장소는 null로 지정할 수 있음.

교체 후 `npm.cmd run typecheck`, `npm.cmd run lint`, `npm.cmd test` 실행 및 실기기에서 반복 경계·전환 확인. 원본 다운로드 페이지·제작자·라이선스와 출처 표기 조건은 별도 보관.

## 구현 경계

- `src/services/ambientAudio.ts`: 단일 플레이어 수명, 전환, 오래된 비동기 재생 요청 취소, 오류·재시도.
- `src/components/AmbientAudioProvider.tsx`: Expo Audio 어댑터, 앱 활성 상태, 저장 설정 적용.
- `src/components/Sound.tsx`: 실제 상태 기반 조작 UI.
- `src/features/App.tsx`: 화면 흐름에서 현재 재생 공간 결정.
- Expo SDK 58 `expo-audio ~58.0.12` 사용. 앱 내 음원 재생만 구현하며 백그라운드 재생·녹음·마이크 권한은 꺼둠.
- 공식 API 확인: https://docs.expo.dev/versions/v58.0.0/sdk/audio/

MP3의 반복 경계 품질은 기기/디코더에 따라 다를 수 있음. 재생 위치가 정상 반복하는 것과 청감상 무간격인 것은 다른 검증 항목이며, 필요 시 WAV 또는 별도 재생 처리로 교체 가능.
