## 적용 위치
- 장소 카드: 위 배경을 재사용해 정사각형 영역에서 cover. 원본을 변경하지 않고 표시 영역만 자른다.
- 입장/채팅/배경 보기: 같은 장소 배경 사용. 장소별로 배경이 달라지지 않게 한다.
- 채팅: 배경이 화면 위쪽 약 35~45%에서 충분히 보이고 아래는 아이보리 패널. 키보드가 나오면 배경 높이를 줄여 입력·최근 메시지를 확보한다. 퍼센트는 기준이며 작은 화면에서 접근성을 우선한다.
- 프로필: 메시지 옆 32~40dp, 헤더 44~56dp 원형 crop. 전체 얼굴이 보이도록 중앙 조정. 풍경 위 대형 캐릭터 금지.
- 그림일기: assets/diary/demo-art.png, 전체 구도가 보이게 contain. 내 기록/피드 썸네일도 재사용한다.
- 음원 미리보기 썸네일은 장소 배경 재사용. 재생·정지·음소거·뒤로·그림일기 전환은 벡터 아이콘.
- 로고는 앱 이름 텍스트와 잎 아이콘 조합. 스토어 아이콘·스플래시 전용 디자인은 이번 범위 밖이다.

## 기본 스타일
바탕 #F7F4ED, 패널 #FFFCF7, 본문 #222922, 보조글 #687168. 간격 4/8/12/16/24/32dp. 본문 16~17sp, 제목 22~28sp, 한국어 시스템 폰트 우선. 패널 상단 반경 28~32dp, 버튼 48~56dp 높이, 터치영역 최소 44dp. 버튼 글자는 대비 확인. 흰 글자가 있는 배경 상단에 어두운 gradient를 얇게 넣는다.
가로 360~430dp 기준으로 고정폭 대신 flex와 safe area 적용. 큰 글자에서 잘림 방지. 상태바 시각·배터리는 이미지로 그리지 않는다. 배경/프로필은 장식 이미지, 버튼에는 읽기 가능한 접근성 라벨을 준다.

assets/manifest.json은 실제 크기·출처 파일·해시 목록이다. PNG 원본은 보존한다. 최적화본을 만들 경우 별도 경로와 대응 관계를 기록한다.
