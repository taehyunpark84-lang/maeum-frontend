# 5. 완료 확인 기준
## 기능 수동 확인
- 처음 시작/재시작에서 닉네임·기록 복원, 네 장소 선택·진입·뒤로가기.
- 네 장소 모두 올바른 배경·프로필·강조색 사용.
- 메시지 입력/전송/스크롤, 키보드와 입력창 겹침 없음, 전송 실패 재시도.
- 대화 재개와 장소 변경 시 세션 분리, 배경만 보기 복귀.
- 음원 없는 상태에서 크래시·거짓 재생 표시 없음.
- 일기 생성 로딩/실패/취소, 감정 해석 수정, 본문 수정 저장, 재시작 후 유지.
- 비공개 기본값, 공유 미리보기, 게시 취소, 피드 반응과 로컬 시연 표시.
- 삭제 확인/취소, 빈 목록, 전체 초기화, 긴 문장·큰 글씨.

## 개발 확인
선택한 도구에 맞게 typecheck/lint 실행. 지원되는 Android 또는 iOS 환경에서 실제 화면 확인 후 화면 캡처를 docs/screenshots/에 남긴다. 기기 실행이 불가능하면 정적 검증만 했다고 명시하고 사용자의 기기 확인 절차를 제공한다. 웹 미리보기 통과를 모바일 검증 완료로 쓰지 않는다.
의미 있는 테스트는 세션 분리, 저장·복원, 공개 게시물에서 개인 데이터 제외, mock 실패 후 복구에 집중한다. 외형만 복제하는 과도한 단위 테스트는 피한다.
결과는 docs/PROGRESS.md에 실제 실행 명령·성공/실패·미검증 항목을 기록한다. 유료 배포·스토어 업로드는 범위 밖이다.
