# 2. 화면과 흐름
주요 화면은 6종 이내. 세부 설정은 모달/바텀시트로 통합한다.

| 화면 | 주요 요소 | 이동·상태 |
|---|---|---|
| 시작 | 앱 이름, 닉네임 입력, 시작 | 입력 후 공간 선택. 기존 닉네임이면 생략 |
| 공간 | 2열 장소 카드, 풍경, 캐릭터 이름, 소리 설명, 선택 표시, 입장 버튼 | 선택 장소 소개를 바텀시트로 표시 후 채팅. 최근 대화는 같은 화면의 탭/시트 |
| 채팅 | 풍경, 제목, 작은 프로필, AI 표시, 말풍선, 입력창, 소리 조절, 그림일기 버튼 | 입장 소개/대화/배경만 보기 상태. 장소 변경 시 기존 방 보관 후 새 방 생성 |
| 그림일기 | 요약·감정 확인, 생성 중, 작품, 시적 본문, 수정·저장·공유 | 하나의 화면에서 단계 전환. 저장된 일기도 이 화면 재사용 |
| 내 기록 | 일기 썸네일·제목·날짜, 대화 목록 탭 | 일기 상세 또는 대화 재개. 빈 목록·삭제 확인 |
| 공감 피드 | 그림·시, 익명 별칭, 공감 반응 | 로컬 시연 표시. 댓글·신고·차단은 모달 |

## 구체적 동작
- 공간/내 기록/공감 피드는 하단 탐색으로 이동. 몰입 채팅과 일기 편집에서는 하단 탐색 숨김.
- 채팅 뒤로가기는 메시지를 보관하고 공간으로 돌아간다. 기록에서 선택하면 같은 sessionId로 재개한다.
- 장소 변경은 새 세션이다. 기존 메시지를 다른 캐릭터의 대화처럼 바꾸지 않는다.
- 배경만 보기는 패널을 숨기고 복귀 버튼을 유지한다. Android 뒤로가기도 패널 복귀부터 처리한다.
- 전송은 공백 입력 금지, 대기 중 중복 전송 방지, 실패 메시지에 재시도. 사용자가 위로 스크롤 중이면 강제 하단 이동하지 않는다.
- 그림일기는 사용자 발화가 있어야 시작한다. 요약·감정 편집 후 생성, 취소·실패·재시도 상태를 제공한다.
- 기본 데모 대화에는 제공된 작품과 일기를 사용한다. 임의 대화에도 동일 그림을 쓸 경우 반드시 '예시 작품'으로 표시하며 실제 맞춤 생성이라고 하지 않는다.
- 생성 중 화면을 나가도 취소/완료 처리를 명확히 하고 중복 일기를 만들지 않는다.
- 저장 후 다시 열면 수정 본문이 유지되어야 한다. 재생성 시 기존 편집 내용을 덮어쓸지 확인한다.
- 공유는 그림·제목·사용자가 승인한 본문만 복사한다. 대화·감정 점수·실명·세션 식별자는 공개 모델에 넣지 않는다. 로컬 피드는 다른 사람에게 전송되지 않는 시연이다.
