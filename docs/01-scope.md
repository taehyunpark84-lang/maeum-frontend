# 1. 제품과 구현 범위
선택한 장소의 풍경과 소리 속에서 작은 AI 캐릭터와 대화하고, 마음과 경험을 그림·시적 일기로 남기는 앱. 대상은 일상과 속마음을 나눌 상대가 부족한 사람이다.

## 이번 MVP 필수
- 닉네임으로 로컬 시작(로그인 인증 아님), 장소 선택 4종, 장소별 소개와 채팅.
- 메시지 입력·전송·시연 답변·대화 저장·지난 대화 이어하기.
- 배경만 보기, 장소 변경, 음원 준비 상태와 볼륨 UI.
- 대화 내용 확인·수정 → 그림일기 시연 생성 → 제목·본문 수정 → 보관.
- 일기 목록/상세, 삭제 확인, 익명 공유 미리보기와 로컬 공감 피드.
- 비공개 기본값, 공유 취소, 공감 버튼 및 댓글·신고·차단 시연은 피드 안의 모달로 구성.

## 나중에 연결
FastAPI 인증·DB, KoBERT 또는 KoELECTRA 감정 예측, GPT 대화, 이미지 생성, 실제 공유·신고 처리, 음원 확보. 교회·공원·수목원 등 추가 장소도 이후 확장한다. 현재 선택 화면에는 구현한 4곳만 표시한다.
자동 진단·치료 효과·정확한 감정 단정은 하지 않는다. 감정은 사용자가 확인하고 고칠 수 있는 해석으로 표현한다.
